# CSS Grid Responsive Layout

This project is a simple responsive card layout built using HTML and CSS Grid.


## Goal of this project

The goal is to learn and practice:
- CSS Grid layout system
- Responsive design using auto-fit and minmax
- Creating card-based UI layouts


## What I learned

- How CSS Grid works
- How to use `repeat()`
- How `auto-fit` and `minmax()` create responsive layouts
- How to build flexible card grids


## Responsive behavior

- Cards automatically adjust based on screen size
- No fixed number of columns
- Layout adapts to mobile, tablet, and desktop
